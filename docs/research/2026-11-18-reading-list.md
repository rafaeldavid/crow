# Reading list, 2026-11-18

**State: a reference, complete for its date.** On 2026-11-16 Rafa asked for a session of reading before the next phase of work is planned, and on 2026-11-18 he asked that the list be kept here for the project (T-506). One session read twelve works that day and drew on five more from memory. This file lists them, with where each is freely readable and which of Crow's principles it bears on. The notes on what the reading suggests for Crow's plans are kept privately (`docs/private-materials.md`).

Each work is marked **read** (the text was read in the session on 2026-11-18, with the share read) or **recalled** (drawn from the model's training, not read that day). Every address was fetched on 2026-11-18. Use only copies that are lawfully free.

## How the list was made

- The session chose the works itself, from four questions about trust between strangers and one about craft.
- It read only what is freely and lawfully readable, bought nothing and signed up for nothing.
- Project Gutenberg's main site answered 503 that day, so its books came from a mirror, `gutenberg.pglaf.org`.
- One request that named a browser as the reader was refused by the session's safety classifier and was not retried. The article it was for is not on this list.
